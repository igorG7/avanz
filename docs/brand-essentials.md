# Paleta oficial

| Papel        | Nome         | Hex       | Uso recomendado                         |
|--------------|--------------|-----------|------------------------------------------|
| **Primária** | Azul Marinho | `#0F172A` | Hero, header, footer, fundos escuros    |
| **Destaque** | Laranja      | `#F97316` | CTA, links, badges, acentos visuais     |
| **Branco**   | —            | `#FFFFFF` | Fundos claros, texto sobre azul         |
| Cinza claro  | —            | `#E5E7EB` | Divisores, backgrounds neutros          |
| Cinza médio  | —            | `#64748B` | Texto secundário, metadata              |
| Cinza escuro | —            | `#1E293B` | Texto principal sobre branco            |

---

# Regra de composição

## Hierarquia visual
O **azul marinho** domina.
O **laranja** funciona apenas como:
- acento
- direção visual
- ponto de ação

## Limite recomendado
> Não usar laranja em mais de ~10% da composição visual.

Se tudo é destaque, nada é destaque.

---

# Tipografia

## Primária — Inter
Uso:
- body
- UI
- descrições
- formulários
- micro-copy

Características:
- moderna
- limpa
- altamente legível
- ótima em mobile

## Secundária — Montserrat
Uso:
- headlines
- números
- callouts
- hero sections

Características:
- geométrica
- forte
- mais marcante visualmente
